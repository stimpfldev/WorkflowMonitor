# Workflow Monitor Demo

The Demo edition is a local technical evaluation of Workflow Monitor.

## Included

- 30 days of evaluation
- Up to 3 registered processes
- 1 Worker/integration
- Local Web dashboard
- REST API
- Real execution processing
- Execution history and detail
- Success/failure status
- Duration metrics
- Correct/incorrect/affected-row metrics
- Filters and CSV export
- Spanish and English interface
- Reusable sample CSV

## After expiration

When the 30-day period expires, the Demo remains available in read-only mode so the recorded information can still be reviewed.

## Sample workflow

A reusable sample file is installed at:

```text
C:\SqlWorkflowMonitor\Data\Samples\customers.csv
```

Copy it to:

```text
C:\SqlWorkflowMonitor\Data\Input\customers.csv
```

The expected sample result is:

```text
Process: Importación de clientes
Status: Successful
Total: 3
Correct: 2
Incorrect: 1
Affected rows: 2
```

## Not intended for production

The Demo is intended for evaluation. Production use should use a licensed Professional or Enterprise package with the corresponding limits and deployment configuration.
