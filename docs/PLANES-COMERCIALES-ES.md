# Workflow Monitor — Planes comerciales

Workflow Monitor se licencia por instalación y capacidad. Professional y Enterprise utilizan el mismo núcleo funcional; cambian los límites licenciados de procesos y Workers/integraciones.

| Plan | Precio | Procesos registrados | Workers / integraciones | Uso recomendado |
|---|---:|---:|---:|---|
| Demo | Gratis | Hasta 3 | 1 | Evaluación técnica durante 30 días |
| Professional | USD 15/mes o USD 149/año | Hasta 25 | Hasta 5 | Entornos productivos pequeños y equipos backend focalizados |
| Enterprise | USD 39/mes o USD 399/año | Hasta 100 | Hasta 20 | Entornos productivos mayores y múltiples integraciones |
| Enterprise Custom | A cotizar | Más de 100 | Más de 20 | Varias instalaciones o límites especiales |

## Qué incluye Professional y Enterprise

- Dashboard web autenticado
- API REST
- Historial y detalle de ejecuciones
- Estados Running, Succeeded, Failed y Cancelled
- Métricas de procesamiento
- Detección de ejecuciones demoradas
- Filtros, ordenamiento, paginación y exportación CSV
- Worker Service e integración con SQL Server
- Autenticación por API key para Workers/integraciones
- Español e inglés
- Validación de licencia firmada sin conexión a Internet

## Facturación

El cliente puede elegir pago mensual o anual. El pago anual tiene descuento respecto de doce pagos mensuales.

La licencia se emite para una instalación concreta y contiene su fecha de vencimiento y sus límites de capacidad. Por ese motivo, el mismo producto puede operar con períodos mensuales o anuales sin cambiar el ejecutable.
