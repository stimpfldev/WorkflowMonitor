## Qué incluye Professional y Enterprise

- Dashboard web autenticado
- API REST
- Historial y detalle de ejecuciones
- Estados Running, Succeeded, Failed y Cancelled
- Métricas de procesamiento
- Detección de ejecuciones demoradas
- Filtros, ordenamiento, paginación y exportación CSV
- Worker Service e integración con SQL Server
- Autenticación por API key para Workers/integraciones
- Español e inglés
- Validación de licencia firmada sin conexión a Internet

## Facturación

El cliente puede elegir pago mensual, trimestral, semestral o anual. Los períodos más largos tienen descuento respecto de pagar la misma cantidad de meses mediante mensualidades independientes.

Cada licencia paga se emite para una instalación concreta y contiene su fecha de vencimiento y sus límites de capacidad. El mismo producto puede operar con distintos períodos comerciales sin cambiar el ejecutable.

## Compra y activación

El flujo comercial de suscripción y cobro online mediante Mercado Pago fue validado de punta a punta. Una compra confirmada queda registrada como activa en el sistema comercial y permite emitir la licencia correspondiente al plan, período e Installation ID contratados.

Las licencias Professional y Enterprise se distribuyen por separado de la Demo pública. Para consultas comerciales o emisión de licencias: **contacto@federicostimpfl.com.ar**.
